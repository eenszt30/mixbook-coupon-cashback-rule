## The fine print that changes your real total

Mixbook allows exactly one coupon code per order, and none of them stack with each other, vouchers, or Groupon deals. You can't apply a code after placing an order, and Mixbook won't retroactively adjust a previous purchase — so the code goes in the "coupon code" field on the cart/checkout page *before* payment, and you should watch the subtotal update to confirm it took.

The free shipping math trips people up. With SHIPMIX, the $79 threshold applies to your total *after* the 35% discount, not before — so a $100 cart at $65 after discount doesn't qualify. Shipping coverage is also narrower than "free shipping" suggests: US Economy shipping applies only to the continental United States, with a parallel version covering standard shipping to Canada. Orders under the threshold, or to Hawaii, Alaska, and other regions, pay normal shipping on top.

Other conditions that apply to every code: taxes still apply, gift card purchases are excluded, and discounts only apply to completed projects at checkout. One more thing worth knowing before you comparison-shop: Mixbook doesn't price match other photo printing sites. Their official page says so directly and points you to their email list instead, since their promos rotate weekly. If your whole decision hinges on beating another printer's quoted price, a coupon code may not close the gap on its own.

One caution from general coupon-stacking best practice: don't create a duplicate account to reuse a first-order deal — that can violate a retailer's terms and complicate returns or rewards.

## FAQ

**Why isn't my Mixbook coupon code working?**
Four usual reasons, and Mixbook's terms confirm most of them: the code expired (check the dates above — several lapse on 10/31), your cart contains excluded items like 6x6" or Softcover books or Magnets, the discount is applied on the pre-discount total rather than the $79-after-discount threshold you assumed, or the code is restricted to new customers or specific products. A third-party aggregator code may also simply have been deactivated — that's why you confirm the subtotal changed before paying.

**Can I use two Mixbook coupon codes on one order?**
No. One code per order, and codes don't combine with vouchers or Groupon deals. You can, however, place multiple orders and use a different code on each — which is exactly how people run the calendar deals (18CAL for an 11x8.5" at $18, then FRESHCAL on a second order for a 12x12" at $23).

**Is cashback worth it if I'm already using a 50% code?**
Usually not, unless the code is one displayed on the cashback site's own page — and remember that pairing an unlisted code with cashback voids the cashback. For a typical single photo book, the 50% code saves several times what 6% cashback would. Cashback earns its keep on code-free orders and small repeat purchases.

**Does Mixbook price match competitors?**
No. Mixbook states this on its own coupon FAQ page. Its alternative is a weekly promo rotation, so if a code isn't running this week, subscribing to the email list is their suggested path to the next one — and for new customers that same sign-up doubles as the route to the one-time 50%-off-first-order code.
